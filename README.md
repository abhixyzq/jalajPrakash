# Advora Creative Studio — Jalaj Prakash Portfolio

A modern, high-performance, and secure React portfolio application for **Jalaj Prakash** (Advora Creative Studio) specializing in luxury advertising campaigns, product visuals, brand creatives, and visual storytelling.

Built with **React 19**, **Vite**, **Tailwind CSS**, and modern glassmorphism design architecture.

---

## ✨ Features

- **Obsidian & Champagne Luxury Aesthetic**: Deep obsidian backgrounds (`#070709`) with delicate mesh grid texture, ambient gold backlight glows, and Syne typography.
- **Interactive Portfolio Showcase**:
  - Filter by category: *All*, *Advertising*, *Product*, *Social Carousels*, *AI Concepts*.
  - Color palette swatch indicators with hex codes.
  - Case Study modal with full art direction narrative, client, year, and live Instagram links.
- **Built-in Studio CMS Mode**:
  - Toggle "Edit Mode" from the top navigation.
  - Add new campaigns with image upload / URL, color palettes, and descriptions.
  - Edit or delete existing projects.
  - Upload or change designer portrait photo.
  - Edit bio, tagline, and contact info.
  - LocalStorage persistence with 1-click Reset to curated defaults.
- **Instant Deployment & Export**:
  - Export full JSON configuration for backup.
  - Ready for 1-click hosting on Netlify, Vercel, or GitHub Pages.
- **Capabilities & Services**:
  - Social Media Advertising, Product Advertising, Brand Visuals, Posters & Thumbnails, AI-Assisted Design, and Creative Direction.
- **About Jalaj Prakash**:
  - Creative journey, tool stack (Canva Pro, AI Generative Tools, Photoshop, DaVinci Resolve), execution pillars, and Instagram spotlight.
- **Interactive Contact**:
  - Direct `mailto:` action with quick copy-to-clipboard toast confirmation.
  - Sleek client inquiry form with input validation and instant feedback.
- **Security & Performance**:
  - `rel="noopener noreferrer"` and safe URL scheme sanitization preventing `javascript:` injection.
  - React JSX escaping preventing XSS vulnerabilities.
  - Ultra-fast page load: optimized image assets instead of 18MB base64 HTML blob.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```
The optimized bundle will be generated in the `dist/` directory ready for deployment.

### 4. Preview Production Build
```bash
npm run preview
```
